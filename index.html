推荐 · 首次使用

轻量版

软件本体，不含模型。首次启动自动从 ModelScope 下载约 1GB 模型（一次即可，之后完全离线）。适合网络条件好的用户。

安装包约 320MB 下载轻量版
开箱即用

完整版

软件 + Qwen2.5-0.5B 模型打包在一起，解压即用，无需联网下载模型。适合网络条件一般或想立刻体验的用户。

安装包约 1.1GB 下载完整版

使用方法

1下载安装包（zip），右键 → 解压到当前文件夹
2进入解压后的 Star 文件夹，双击 Star.exe 打开软件窗口
3轻量版首次启动会自动下载模型，进度条走完即可开始对话
4浏览器访问 http://127.0.0.1:8123/ 也可以使用同一个服务
⚡ 检测到 NVIDIA 显卡时，软件内会提示可安装 GPU 加速组件：推理速度提升约 3–5 倍。当前版本为 CPU 版（N 卡也能跑，只是稍慢），GPU 加速组件包将随后发布。
