推荐 · 首次使用

轻量版

软件本体，不含模型。首次启动自动下载对话模型（约 1GB）与绘画模型（约 2.6GB），之后完全离线。

安装包约 234MB 下载轻量版
开箱即用

完整版

软件 + 对话模型打包在一起，解压即用。绘画模型在绘画页首次使用时自动下载。

安装包约 985MB 下载完整版

使用方法

1下载安装包（zip），右键 → 解压到当前文件夹
2进入解压后的 Star 文件夹，双击 Star.exe 打开软件窗口
3顶部切换「对话 / 绘画」：对话支持流式回复与一键复制；绘画输入描述 → 生成图片 → 一键下载
4浏览器访问 http://127.0.0.1:8123/ 也可以使用同一个服务
⚡ 检测到 NVIDIA 显卡时，软件内会提示 GPU 加速。公开下载版为 CPU 版（N 卡也能跑，对话稍慢、绘画约 17 秒/张）；GPU 加速完整版（RTX 系列约 2 秒/张）目前作为开发者本机版，暂未公开分发。
